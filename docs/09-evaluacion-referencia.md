## Registro de observación
Fecha, evaluador, módulo, ID de caso, versión/plan, pasos, resultado observado, limitación, requisito derivado, prioridad y evidencia permitida. Marcar no accesible/no observado cuando corresponda.

## Preguntas al proveedor
Qué carriers y estados cubre cada conexión; API autorizada o importación; alcance de inscripción; sincronización y errores; exportación completa; permisos; límites/costos; retención/borrado; privacidad; soporte y recuperación. Obtener respuesta demostrable, no asumir desde publicidad.
