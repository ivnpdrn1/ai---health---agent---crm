## Cómo avanzar
Cada trabajo tiene ID, requisito, aceptación, dependencias y evidencia. Seleccionar tareas listas del backlog; implementar un flujo completo; probar; registrar resultado y actualizar estado. No marcar terminado por tener una pantalla o un borrador.

**Primer incremento:** acceso por roles → hogar ficticio → póliza → importación validada → tarea de servicio → auditoría. Las conexiones externas se habilitan después de verificar acuerdos, permisos y pruebas.

## Trabajo con ChatGPT y Claude
ChatGPT ayuda a concretar requisitos y revisar resultados; Claude u otro ejecutor implementa tareas delimitadas. Ambos leen [AGENTS.md](AGENTS.md) y el estado actual. Usar [plantilla de tarea](templates/tarea.md), [handoff](templates/handoff.md) y [registro de sesión](templates/sesion.md). El repositorio es la referencia común.

## Manejo de información
Este repositorio es público. Solo código, documentación y datos sintéticos. Clientes, identificaciones, salud, extractos reales, grabaciones, contratos privados y secretos quedan en sistemas autorizados fuera de GitHub. No incluirlos en issues, capturas ni prompts.

El nombre de producto y el stack son provisionales. No hay calendario ni presupuesto comprometidos hasta conocer volumen, migración e integraciones.
